# 环境说明

## 开发环境

| 项目 | 说明 |
|------|------|
| 操作系统 | Windows 10/11 |
| 语言 | Python 3.x |
| IDE | PyCharm / VS Code |
| 依赖库 | 全部使用 Python 标准库，无需额外安装 |

## 运行环境

| 项目 | 说明 |
|------|------|
| Python 版本 | Python 3.8 及以上 |
| 依赖包 | `tkinter`（Python 标准库自带） |
| 启动方式 | `python app.py` |

## 依赖说明

- `tkinter` — GUI 界面（Python 标准库，无需 pip 安装）
- `json`, `os`, `datetime` — 数据处理（Python 标准库）
- `pytest` — 仅运行单元测试时需要（`pip install pytest`）

## 运行方式

```bash
# 启动应用
cd 班级-学号-姓名-待测程序
python app.py

# 运行白盒测试（单元测试）
pytest test_assistant.py -v

# 运行黑盒测试
python run_blackbox_tests.py
```
